# Траты — личный учёт финансов (PWA)

Статичное веб-приложение. Работает офлайн, данные хранятся на устройстве и синхронизируются через Supabase между Safari, иконкой на экране «Домой» и другими устройствами. Вход по email и паролю, регистрация только по коду доступа.

## Возможности
- Ручное добавление трат, свои категории с цветами, месячная сводка с разбивкой по категориям
- Фото чека: распознавание (Tesseract.js, rus+eng), сумма, магазин и дата подставляются, ты проверяешь и сохраняешь
- Apple Pay: автозапись через «Быстрые команды»
- Облачная синхронизация (local-first: без сети всё работает, потом догоняет)
- Мультивалютность: трата хранится в валюте оплаты (злотый, евро и т.д.), итоги считаются в основной валюте по курсу ЕЦБ на дату траты (Frankfurter, запасной open.er-api.com). Основная и валюта по умолчанию задаются в настройках
- Экспорт и импорт JSON

## 1. GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root → Save. Сайт: `https://ЛОГИН.github.io/РЕПО/`.

## 2. Облако (Supabase)
0. Для валют (если базу создавал раньше): `alter table public.transactions add column if not exists cur text, add column if not exists rates jsonb;`
1. SQL Editor → выполни `supabase.sql` (таблицы и правила доступа: каждый видит только свои данные).
2. SQL Editor → выполни `invite.sql` (проверка кода доступа при регистрации на сервере).
3. Придумай свой код и добавь отдельным запросом (в репозиторий его не кладём):
   `insert into public.invite_codes (code, max_uses) values ('ТВОЙ-КОД', 3);`
   `max_uses`: сколько раз код можно использовать. Сменить код: удалить строку и добавить новую.
4. Authentication → Sign In / Providers → Email: выключи **Confirm email**.
5. Админка: выполни `admin.sql` (в конце файла укажи id своего пользователя). В приложении у администратора в настройках появится раздел «Администрирование»: список пользователей и смена пароля любому из них. Забытый пароль восстанавливается через администратора, почта не нужна.
6. `config.js`: Project URL и anon public key (публичные значения; защита обеспечена RLS). **Service role key** нигде не используй и не публикуй.

## 3. Иконка на экране «Домой»
Safari → «Поделиться» → «На экран Домой». Входить нужно отдельно в Safari и в иконке: у них раздельное хранилище, но после входа данные общие.

## 4. Автозапись при оплате Apple Pay
Команды → Автоматизация → + → Wallet → «Автоматизация» включена, «Уведомление» выключено → действие «Открыть URL»:
```
https://ЛОГИН.github.io/РЕПО/#add?amount=[Сумма]&merchant=[Продавец]
```
`Сумма` и `Продавец` — свойства переменной «Ввод команды». Ссылка открывается в Safari, трата записывается и уходит в облако; в иконке появится при следующем открытии. Валюта по умолчанию берётся из настроек; можно добавить `&cur=PLN` или передать сумму с кодом валюты. Без суммы (`#add`) приложение открывает форму добавления.

## Бэкап
Настройки → Экспорт в файл. Облако основное хранилище, но экспорт не помешает.

## Тесты
E2E на Playwright (Chromium), Supabase и API курсов подменены моками:
```
npm i -D playwright   # один раз
node tests/e2e.js
```
Покрывают: добавление в разных валютах, конвертацию, правку и удаление, смену основной валюты, Apple Pay-ссылку (`#add?...`), доставку курса после офлайна, календарь, разбор чека, вход, синхронизацию и удаление аккаунта.
