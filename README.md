# Траты — личный учёт финансов (PWA)

Статичное веб-приложение. Работает офлайн, данные хранятся на устройстве и (по желанию) синхронизируются через Supabase между Safari, иконкой на экране «Домой» и другими устройствами.

## Возможности
- Ручное добавление трат, категории (можно добавлять/удалять), месячная сводка
- 📷 Фото чека → OCR (Tesseract.js, rus+eng) → сумма/магазин/дата подставляются, ты проверяешь и сохраняешь
- Apple Pay → автозапись через «Быстрые команды»
- Облачная синхронизация: вход по email и паролю, local-first (без сети всё работает, потом догоняет)
- Экспорт/импорт JSON

## 1. GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root → Save. Сайт: `https://ЛОГИН.github.io/РЕПО/`.

## 2. Облако (Supabase, бесплатно)
1. supabase.com → New project (запомни пароль БД, он не понадобится приложению).
2. **SQL Editor → New query** → вставь содержимое `supabase.sql` → Run.
3. **Authentication → Sign In / Providers → Email**: выключи **Confirm email** (иначе после регистрации нужно подтверждать почту).
4. **Project Settings → API**: скопируй **Project URL** и **anon public key**.
5. Вставь их в `config.js` и закоммить. Ключ anon публичный по замыслу: данные защищены правилами Row Level Security из `supabase.sql` (каждый видит только свои строки). **Service role key нигде не используй и не публикуй.**
6. В приложении: ⚙︎ → Облачная синхронизация → Регистрация (первый раз), потом на других устройствах — Войти. Войти нужно отдельно в Safari и в иконке: у них раздельное хранилище, но после входа данные одни и те же.

## 3. Иконка на экране «Домой»
Safari → «Поделиться» → **На экран «Домой»**.

## 4. Автозапись при оплате Apple Pay
Команды → Автоматизация → + → Wallet → «Автоматизация» включена, «Уведомление» выключено → действие **Открыть URL**:
```
https://ЛОГИН.github.io/РЕПО/#add?amount=[Сумма]&merchant=[Продавец]
```
(`Сумма`/`Продавец` — свойства переменной «Ввод команды».) Ссылка откроется в Safari, трата запишется и уйдёт в облако; в иконке появится после синхронизации (при открытии приложения). Один раз войди в аккаунт и в Safari.

Без суммы (`#add`) приложение просто открывает форму добавления.
