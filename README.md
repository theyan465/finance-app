# Траты — личный учёт финансов (PWA)

Статичное веб-приложение: без сервера, данные хранятся на устройстве (localStorage). Работает офлайн.

## Возможности
- Ручное добавление трат, категории (можно добавлять/удалять), месячная сводка
- 📷 Фото чека → OCR (Tesseract.js, rus+eng) → сумма/магазин/дата подставляются, ты проверяешь и сохраняешь
- Apple Pay → автозапись через «Быстрые команды» (см. ниже)
- Экспорт/импорт JSON (делай бэкап!)

## 1. Выложить на GitHub Pages
1. Создай репозиторий на github.com → **Add file → Upload files** → загрузи все файлы из этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `README.md`).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**.
3. Через ~1 минуту сайт будет на `https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`.

## 2. Установить на iPhone
Открой ссылку в **Safari** → «Поделиться» → **На экран «Домой»**. Дальше работает как приложение.

## 3. Автозапись при оплате Apple Pay
Приложение «Команды» (Shortcuts) → **Автоматизация → + → Транзакция**:
1. Выбери карты/Wallet, которые отслеживать, условия — любая оплата.
2. Выбери **Запускать сразу** (Run Immediately).
3. Действие **«Открыть URL»**, адрес:
   ```
   https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/#add?amount=[Сумма]&merchant=[Продавец]
   ```
   где `[Сумма]` и `[Продавец]` — переменные, которые вставляются из «Ввода команды» (тап по полю → «Сумма» / «Продавец» / «Название»).
4. Готово: после оплаты откроется приложение, трата запишется и категория подберётся по названию магазина.

Параметры ссылки: `amount`, `merchant`, необязательно `cat` (точное название категории) и `date` (`2026-11-03`).
Автоматизация работает только для карт в Apple Wallet. Проверь, что Safari-версия и «домашняя» PWA используют разное хранилище: пользуйся только установленной иконкой.

## 4. Перенос в App Store (потом)
- Apple Developer Program стоит **$99 в год** (не разово).
- Оболочка: [Capacitor](https://capacitorjs.com): `npm i @capacitor/core @capacitor/cli @capacitor/ios`, `npx cap init`, положи файлы в `www/`, `npx cap add ios`, открой в Xcode (нужен Mac).
- Apple может отклонить «голую» обёртку сайта (правило 4.2). Для одобрения добавляют нативные штуки: Face ID, push-напоминания, нативная камера, App Intents для Apple Pay вместо URL.
- До этого момента можно пользоваться PWA бесплатно.
